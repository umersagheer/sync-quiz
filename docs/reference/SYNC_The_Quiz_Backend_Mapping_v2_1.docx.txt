2 · Engine rules
Eight global rules enforced above every lane. All locked.
#
	Rule
	Definition
	R1
	Lane assignment
	Screen 3 goal sets the lane; the lane sets the base. Metabolic→DEFINE · Recovery→REPAIR · Performance→PERFORM · Skin/longevity→RESTORE · Sex drive→PT-141.
	R2
	Depth read
	Read from TWO signals together: Screen 4 (depth_single / depth_layered) PLUS Screen 5 discriminator boxes checked in the lane. 1 box reads shallow; 2+ reads layered. Depth flips via the per-lane trigger.
	R3
	One blend max
	At MOST ONE advanced blend, ever. Anything else is a single. Engine may push a blend + a single, never advanced + advanced.
	R4
	Cross-lane single
	Each cross-lane secondary can bolt on ONE single from that lane — never a blend. Selection of WHICH single = R8 default.
	R5
	Primary wins
	Shallow primary, deeper secondary: primary always wins. Chosen goal gets the blend or single it earns; secondary caps at a single.
	R6
	Hormonal single-only
	PT-141 returns a single only (blend is phase 2). No depth read.
	R7
	Adjunct-blend dedup
	If a cross-lane single OR pairs-well-with molecule is already inside the primary blend's components, substitute per §2A table. If no substitute exists, drop the adjunct and show the blend solo.
	R8
	Cross-lane secondary defaults
	When a secondary lane is flagged but its discriminators don't fire, the engine bolts on that lane's designated default single. Defaults: REPAIR→BPC-157 · PERFORM→Sermorelin · DEFINE→MOTS-c · RESTORE→NAD+ · PT-141→PT-141. Then R7 dedup runs on the pair.
